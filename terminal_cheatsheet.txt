To run ls -la on the results of the find command, you can use a combination of find and xargs. xargs will take the output of find and apply ls -la to each result. Here's how you can modify your command:


find / -perm -4000 2>/dev/null | xargs -r ls -la
Here’s what each part does:

find / -perm -4000 2>/dev/null: Finds files with the setuid bit set and suppresses error messages.
|: Pipes the output of find to xargs.
xargs -r ls -la: xargs takes each line of input (each file found) and runs ls -la on it. The -r option ensures that ls -la is only run if there is input.
If there are filenames with spaces or special characters, you should use find with -print0 and xargs with -0 for safer handling:



find / -perm -4000 -print0 2>/dev/null | xargs -0 -r ls -la
-print0 makes find output filenames followed by a null character.
-0 tells xargs to expect input separated by null characters, which handles spaces and special characters properly.
